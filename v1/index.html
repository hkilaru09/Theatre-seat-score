    How the score works

    Each seat gets six factor scores between 0 and 1, computed from the room's real geometry: screen size and height, distance to each row, row rise and seat position. The total is the weighted average of those factors on a 0 to 100 scale, using the weights you set.

    The group finder looks along each row for runs of open seats with no aisle in between. It slides a window of your group's size along each run and ranks blocks by 75% average score and 25% worst seat, so nobody in the group ends up with a bad seat.

    Bookings shown on load are a random sample, not live data. Good seats are more likely to be taken, as they are in real theaters.
